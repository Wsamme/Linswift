# Linswift Chrome Extension

Chrome MV3 原型扩展，用来在英文网页和 YouTube 视频里识别你可能不会的单词，并把学习结果同步回 Linswift 账户。

## 当前能力

- 点击扩展图标，在网页右下角打开 Linswift 悬浮球 / 浮层
- 一键扫描当前网页可见文本
- 在 YouTube `watch` 页面自动切换到“字幕模式”
- 采集当前视频字幕，并生成视频级陌生词列表
- 支持 YouTube 字幕的 `原文 / 双语 / 生词` 三种辅助模式
- 按词频和你的词汇阶段筛选“疑似不会词”
- 页面内高亮定位该词
- 鼠标选中网页中的单词后，直接弹出橙色高亮词卡翻译
- 登录 Linswift 账号，同步同一账户的词库、收藏与掌握状态
- 已掌握 / 收藏状态自动写回 `user_vocabulary`
- 可选开启“页内直译 / 字幕生词提示”，把陌生词直接显示为橙色高亮并附带提示
- 支持在浮层里切换目标语言：简中、繁中、English、日语、韩语
- 支持卡片式“先学习”流程，学完回到原网页或视频
- 未配置 AI 时，回退到免费英文词典接口

## 安装

1. 打开 `chrome://extensions`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择目录 `Linswift/chrome-extension`

注意：

- 不要选仓库根目录 `Linswift`，`manifest.json` 不在这里
- 不要直接依赖 `chrome-extension.crx`，开发阶段应使用“加载已解压的扩展程序”

## 使用

1. 打开任意英文网页，或打开有英文字幕的 YouTube `watch` 视频
2. 点击扩展图标
3. 页面右下角会出现 Linswift 浮层
4. 登录 Linswift 账号，完成词库同步
5. 选择你的词汇阶段、目标语言
6. 网页模式下点击“先学习”或“重新扫描”
7. YouTube 模式下先打开字幕，再点击“先学字幕词”或“刷新字幕”
8. 在结果中使用：
   - `定位`：在页面里高亮并滚动到该词
   - `定位`：在 YouTube 当前字幕里打开该词的悬浮词卡
   - `掌握`：加入已掌握，并同步到云端词库
   - `收藏`：加入收藏夹，并同步到云端词库
9. 直接在网页正文里用鼠标选中单词，也会出现橙色高亮和悬浮词卡
10. 如需直接在正文或字幕里看辅助提示，可开启“页内直译 / 字幕生词提示”
11. 点击“继续阅读”可缩成右下角悬浮球，之后随时恢复

## 说明

- 这是第一版 Chrome 原型。识别“不会词”仍是基于词频 + 出现次数 + 词长的启发式算法，不是直接读取用户的真实掌握度。
- YouTube MVP 当前仅支持 `watch` 页面，不包含 `shorts`。
- 下一步可以继续做：
  - 视频观看后总结
  - AB 重听
  - 重点字幕句收藏
